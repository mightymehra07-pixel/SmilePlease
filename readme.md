# SmilePlease 💗

Cute apology website with a 4\-step sorry flow\.

## Refresh protection

The current step is stored in browser `localStorage` with a 24\-hour expiry\. Refreshing or reopening the page keeps the same step for up to one day\. After 24 hours, it starts from the beginning\.

## GitHub Pages

Upload the files preserving folders, then Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save\.
